HOW THE HERO DECK WORKS (background for Eric, also explained to Copilot
below so it understands the code before touching it)
-------------------------------------------------------------------------------
Your homepage's Hero section is a slide deck built entirely from one
JavaScript array called `heroSlides` near the top of assets/js/main.js.
Each entry in the array is one slide, and is laid out like this:

  ['EYEBROW', 'TITLE TEXT', 'META LABEL', 'Body text.', 'TAG']

A block of code right below the array turns each entry into the actual
slide on the page, and a second small block builds the thumbnail list in
the left-hand rail. Both pieces of code read the array by position (item
1, item 2, item 3, etc.) — not by name — so the order of the 5 items in
each row matters, and changing that order without also changing the code
that reads it will put the wrong text in the wrong place on the page.
