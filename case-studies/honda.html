From violation to fix

I learned Repeated status and consistency violations: shoppers couldn't tell which filters were active or what a click would do.
So I changed Severity-ranked recommendations (not a redesign): persistent filter state, clearer inventory and pricing labels, consistent navigation.
Evaluated via Rated on Nielsen's 0–4 scale: a prioritized punch list a team can act on.

Three catastrophic findings, three fixes

Three findings were rated catastrophic. Each is paired with my recommended fix.

2.5.0 · HomepageCatastrophic

Map controls cut off

The embedded map isn't centered, so some map controls are cut off.

Heuristic: User Control & Freedom, Consistency & Standards

Recommended fixRecenter the map so all controls are fully visible in the default view.
3.0.0 · InventoryCatastrophic

Search bar locks scrolling

Clicking into the search bar makes the page unscrollable, locking the user into the search input until they exit it.

Heuristic: User Control & Freedom

Recommended fixAllow normal page scrolling while search is active, and avoid modal-like behavior unless it is a deliberate full-screen search.
5.3.0 · CheckoutCatastrophic

Accessibility button missing

The accessibility button is not available on the checkout screen, even though it appears on other pages.

Heuristic: Help & Documentation

Recommended fixKeep the accessibility button visible and functional throughout the entire checkout flow.

A fix list, not a critique: Engineering punch list

Rather than delivering subjective design critiques, I translated findings into a phased engineering punch list prioritized by user impact and implementation complexity:

  • Phase 1 (Immediate Hotfixes): Recenter the dealership map embed to reveal cut-off controls and decouple the search input focus state from main-page scroll locks.
  • Phase 2 (Accessibility & Compliance): Restore the global accessibility assistive panel across all checkout steps to ensure ADA compliance.
  • Phase 3 (Conversion Optimization): Re-architect inventory filter persistence so applied vehicle trims and financing filters don't wipe on page refreshes.
