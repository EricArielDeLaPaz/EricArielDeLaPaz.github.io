How I work

Fast, with a human in the loop.

My AI-assisted process, with Study Buddy as the example.

  1. 01Design firstI design the product in Figma before any code exists.Study Buddy: a floating desktop focus companion, designed screen by screen.
  2. 02Write staged change listsI break the build into small, ordered requests for the AI.Study Buddy: the app was built in stages, one change list at a time.
  3. 03AI builds a roundThe AI writes the code for that stage.Study Buddy: Electron, React, and TypeScript across 40+ commits.
  4. 04Review against designsI check every round against my Figma designs.Study Buddy: each round compared with the original screens.
  5. 05Decide and correctI cut, fix, and redirect what does not hold up.Study Buddy: cut features, fixed contrast failures, changed window behavior.
  6. 06ShipI repeat steps 3 to 5 until it is ready to use.Study Buddy: about 14 hours of active build time; Windows, Mac, and Linux installers.

I use AI to move quickly and stay accountable for what ships. Build time counted from commit timestamps.
